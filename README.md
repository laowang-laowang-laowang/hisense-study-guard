# 海信电视 65E3G-PRO 专属：电视学习守护与知识挑战系统 (TV 版)

专为 **海信 65E3G-PRO**（搭载基于 Android 的 JUUI 系统）打造的健康观看守护与寓教于乐软件。

---

## 🌟 核心亮点与攻关实现

1. **投屏与电视原生双重阻断**：
   - 无论电视当前是在播放爱奇艺、腾讯视频、优酷等原生 App，还是正在进行**手机无线投屏（乐播投屏 / 苹果 AirPlay / 安卓 Miracast / DLNA）**，累计时间一到，顶层悬浮弹窗立即弹出！
2. **弹出后画面自动暂停（黑科技）**：
   - 弹窗触发瞬间，通过底层**独占音频焦点抢占（Transient Audio Focus）**与**模拟系统级媒体暂停按键广播（KEYCODE_MEDIA_PAUSE）**，主流视频播放器及投屏软件监听到后**自动暂停播放画面与声音**；
   - 孩子答对题目后，自动恢复播放（Resume Playback），体验流畅自然。
3. **5大题库差异化专属 UI（告别单调）**：
   - 📜 **古诗词**：水墨国风 / 竹青雅韵
   - 📐 **简单数学**：智慧黑板 / 几何粉笔绿
   - 🔤 **简单英语**：活力波普 / 英伦卡通撞色
   - 💡 **生活百科**：温馨生活 / 蔚蓝探索
   - 🌍 **地理自然**：浩瀚星球 / 山川探险
   - 专为电视遥控器设计的大字体、高对比度、遥控器光标焦点放大发光动效。
4. **两套题库机制（内置精品 + U 盘一键热更新）**：
   - **内置 500 道精品题库（每个分类 100 道）**：
     - 📜 古诗词：100 道（小学必背名句、作者、朝代、节日意境）
     - 📐 简单数学：100 道（乘法口诀、四则运算巧算、几何周长面积、单位换算）
     - 🔤 简单英语：100 道（高频核心词汇、反义词、日常生活交际问候）
     - 💡 生活百科：100 道（急救消防安全、垃圾分类、人体健康、生活物理常识）
     - 🌍 地理自然：100 道（中国地理、世界名山大川、宇宙天文、气候地质）
   - **U 盘表格一键更新**：随时将表格（`study_questions.csv`）拷入 U 盘插入电视，点击【一键更新】秒导入！

## 📋 后台功能自定义说明

在电视上打开本软件主界面（`SettingsActivity`），即可直接用遥控器操作：

1. **观看累加提醒时间**：
   - 支持自由加减（例如 20 分钟、30 分钟、45 分钟等），达到该时间立即弹窗并暂停视频。
2. **回答错误增加累加时间**：
   - 支持自由加减（例如 5 分钟、10 分钟等）。
   - 当孩子回答错误时，系统记录惩罚时间，并在屏幕上锁定倒计时 30 秒进行静默思考，同时缩短下一次弹出的间隔。
3. **5大题库开关与数量查看**：
   - 可用遥控器随时勾选/取消勾选任意一个或多个题库（如只想让孩子今天背古诗和算数学，可只勾选古诗词与数学）。
4. **防作弊机制**：
   - 弹窗全屏覆盖，强制拦截遥控器返回键（Back），必须答对题目才能关闭弹窗继续观看。

## 💾 如何使用 U 盘更新题库（方案2）

后续你需要增加新题时，我来为你更新 `study_questions.csv` 文件，你只需要执行以下三步：

1. **将 `study_questions.csv` 拷贝至 U 盘根目录下**；
2. **将 U 盘插入海信 65E3G-PRO 电视背面的 USB 接口**；
3. **在电视上打开本软件，用遥控器点击【💾 插上 U 盘，从 U 盘一键更新题库】**。
   - 电视会自动扫描识别 U 盘中的表格，去重合并到本地，屏幕会弹出提示：“成功从 U 盘更新 XX 道新题目！”。
   - 之后即可拔出 U 盘，新题库永久保存在电视内部。

## 📺 海信 65E3G-PRO 电视端安装指南

1. **生成 APK**：
   - 在电脑上打开 Android Studio，选择 `Open` 打开当前工程目录，点击菜单栏 `Build -> Build Bundle(s) / APK(s) -> Build APK(s)`，即可生成 `app-debug.apk` 或 `app-release.apk`。
2. **开启电视第三方应用安装权限**：
   - 遥控器进入电视「设置」->「通用设置」/「系统设置」->「安全与限制」；
   - 找到「未知来源应用安装」切换为“允许”。
   - *（或在海信聚好看应用商城搜索“应用管家”或“聚好用”，通过里面的 U 盘助手直接读取安装）*。
3. **U盘安装**：
   - 将生成的 APK 拷入 U 盘插到电视，点击安装。
4. **授予关键权限**：
   - 首次安装后打开应用，系统若提示“悬浮窗权限 / 显示在其他应用上层”，务必点击“允许”；
   - 点击界面上的【▶️ 启动电视守护服务】，开启全天候健康护眼守护。
